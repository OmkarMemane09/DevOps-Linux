# User & Group Management

Managing users and groups is essential for **security, access control, and multi-user environments** in Linux.

---

## ⭐ 1️⃣ User Management

### Commands:

| Command | Description | Example |
|---------|-------------|---------|
| `adduser username` | Create a new user | ```sudo adduser omkar``` |
| `useradd username` | Another way to create user | ```sudo useradd -m omkar``` |
| `passwd username` | Set or change password | ```sudo passwd omkar``` |
| `deluser username` | Delete a user | ```sudo deluser omkar``` |
| `usermod` | Modify user details | ```sudo usermod -aG sudo omkar``` → Add to sudo group |
| `whoami` | Show current logged-in user | ```whoami``` |

---

## ⭐ 2️⃣ Group Management

### Commands:

| Command | Description | Example |
|---------|-------------|---------|
| `groupadd groupname` | Create a new group | ```sudo groupadd devops``` |
| `groupdel groupname` | Delete a group | ```sudo groupdel devops``` |
| `usermod -aG group user` | Add user to a group | ```sudo usermod -aG devops omkar``` |
| `groups username` | Show groups of a user | ```groups omkar``` |
| `id username` | Show user ID, group ID, and groups | ```id omkar``` |

---

## ⭐ 3️⃣ Viewing & Controlling Logged-In Users

### Commands:

| Command | Description | Example |
|---------|-------------|---------|
| `who` | List logged-in users | ```who``` |
| `w` | Detailed info about logged-in users | ```w``` |
| `last` | Show login history | ```last omkar``` |
| `finger username` | Show user info | ```finger omkar``` |

---

## ⭐ 4️⃣ File Ownership & Permissions

### Commands:

| Command | Description | Example |
|---------|-------------|---------|
| `chown user:group file` | Change file owner & group | ```sudo chown omkar:devops file.txt``` |
| `chmod` | Change file permissions | ```chmod 755 file.txt``` |
| `chgrp group file` | Change group ownership | ```chgrp devops file.txt``` |

File Permissions & Ownership

Linux uses a **permission and ownership system** to secure files and directories. Understanding this is crucial for system administration and security.

---

## ⭐ 1️⃣ Understanding File Permissions

Linux permissions have **3 types** for **3 categories**:

| Category | Description |
|----------|-------------|
| Owner (u) | File owner |
| Group (g) | Users in the file’s group |
| Others (o) | Everyone else |

**Permission types**:

| Type | Symbol | Description |
|------|--------|-------------|
| Read | r | Can view file contents |
| Write | w | Can modify file contents |
| Execute | x | Can execute file or enter directory |

Check permissions with:

```bash
ls -l filename
```
Example output:
```bash
-rwxr-xr-- 1 omkar dev 1024 Nov 29 2025 script.sh
rwx → Owner can read, write, execute

r-x → Group can read & execute

r-- → Others can only read
```
⭐ 2️⃣ Changing Permissions
Commands:

Command	Description	Example
chmod 755 file	Numeric permission (rwxr-xr-x)	chmod 755 script.sh
chmod u+x file	Add execute to owner	chmod u+x run.sh
chmod g-w file	Remove write for group	chmod g-w config.txt
chmod o=r file	Set others to read-only	chmod o=r notes.txt

Numeric Permissions:

Number	Permission
0	---
1	--x
2	-w-
3	-wx
4	r--
5	r-x
6	rw-
7	rwx

⭐ 3️⃣ Changing Ownership
Commands:
Command	Description	Example
chown user:group file	Change owner & group	chown omkar:devops script.sh
chown user file	Change only owner	chown omkar notes.txt
chgrp group file	Change only group	chgrp devops config.txt

⭐ 4️⃣ Special Permissions
Permission	Symbol	Description
SUID	s	Executes as file owner
SGID	s	Executes as group owner
Sticky bit	t	Only file owner can delete in a directory (common for /tmp)

Example:

```bash
chmod 4755 script.sh   # SUID
chmod 2755 shared_dir  # SGID
chmod +t /tmp           # Sticky bit
```
