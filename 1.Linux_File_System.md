# Linux Architecture & File System

## ⭐ Linux Architecture (Detailed)

Linux architecture is divided into **5 main layers**:

### 1️ Hardware Layer
- Physical components like CPU, RAM, storage, network devices, and peripherals.  
- Linux interacts with hardware **only via the kernel**.

### 2️ Kernel Layer
- Core component of Linux  
- **Responsibilities**:
  - Process management (scheduling, priorities)  
  - Memory management (RAM, swap)  
  - Device drivers (keyboard, disk, network)  
  - File system management  
  - Networking (TCP/IP stack)  
- Types of kernels:
  - Monolithic Kernel (Linux default)  
  - Microkernel (minimal features, more modular)

### 3️ System Libraries
- Libraries provide reusable **code for programs**.  
- Example: `glibc` (GNU C library) for standard file I/O, networking, and threading.  
- Programs call **library functions** instead of writing low-level code.

### 4️ Shell (Command Interpreter)
- Interface between **user & kernel**  
- Converts typed commands to system calls  
- Popular shells: `bash`, `zsh`, `fish`, `ksh`  
- **Example:**  
  ```bash
  echo "Hello, Linux"
   ```
### 5️ User Space / Applications

Programs run in user space (cannot directly access hardware)

Examples: Editors (vim, nano), Browsers, Utilities (curl, wget), DevOps tools (docker, kubectl)

 ## ⭐ Linux File System Hierarchy (FHS)
Linux organizes files in a tree structure starting from / (root).

Key Directories:
Directory	Description
```
/	Root of filesystem
/bin	Essential binaries (commands like ls, cp)
/sbin	System binaries (ifconfig, fdisk)
/etc	Configuration files
/home	User home directories
/root	Root user home
/var	Variable data (logs, databases, spool)
/tmp	Temporary files
/usr	User programs & libraries
/lib	Essential shared libraries
/dev	Device files (/dev/sda, /dev/null)
/proc	Kernel & process information (virtual filesystem)
/sys	System devices & kernel info
```
## ⭐ File System Types

-Ext4 – Most common Linux filesystem

-XFS – High-performance, large files

-Btrfs – Copy-on-write, snapshots

-FAT/NTFS – For cross-platform compatibility

-Swap – Virtual memory area

## ⭐ Processes & System Interaction
Linux treats everything as a file, even devices.

Processes run in user space and interact with kernel via system calls.

Commands like ps, top, htop monitor processes.

```bash
ps aux | grep nginx
top
```
Basic Linux Commands & Navigation

Linux commands are the foundation of system interaction. This chapter covers **file navigation, manipulation, and directory management**.

---

## ⭐ 1️⃣ Navigating the File System

### Commands:

| Command | Description | Example |
|---------|-------------|---------|
| `pwd` | Print working directory | ```bash pwd``` → `/home/omkar` |
| `ls` | List files & directories | ```bash ls -l``` → Detailed list with permissions |
| `cd` | Change directory | ```bash cd /etc``` → Navigate to `/etc` |
| `tree` | Show directory structure | ```bash tree /home``` → Graphical tree view |
| `find` | Search files/directories | ```bash find /home -name "file.txt"``` → Find `file.txt` |

---

## ⭐ 2️⃣ File & Directory Management

### Create, Remove, Copy, Move:

| Command | Description | Example |
|---------|-------------|---------|
| `mkdir` | Create directory | ```bash mkdir projects``` |
| `rmdir` | Remove empty directory | ```bash rmdir old_folder``` |
| `rm -rf` | Remove directory & files recursively | ```bash rm -rf temp_dir``` |
| `touch` | Create empty file | ```bash touch file.txt``` |
| `cp` | Copy file/directory | ```bash cp file.txt backup.txt``` |
| `mv` | Move/rename file | ```bash mv file.txt newfile.txt``` |

---

## ⭐ 3️⃣ Viewing File Contents

| Command | Description | Example |
|---------|-------------|---------|
| `cat` | Display file content | ```bash cat file.txt``` |
| `more` | View file page by page | ```bash more file.txt``` |
| `less` | Scrollable view | ```bash less file.txt``` |
| `head` | Show first 10 lines | ```bash head file.txt``` |
| `tail` | Show last 10 lines | ```bash tail file.txt``` |
| `tail -f` | Monitor file in real-time | ```bash tail -f /var/log/syslog``` |

---

## ⭐ 4️⃣ Searching Inside Files

| Command | Description | Example |
|---------|-------------|---------|
| `grep` | Search text pattern | ```bash grep "error" /var/log/syslog``` |
| `egrep` | Extended regex search | ```bash egrep "error|fail" log.txt``` |
| `wc` | Count lines/words/characters | ```bash wc -l file.txt``` |

---

## ⭐ 5️⃣ File Permissions & Ownership (Basic)

| Command | Description | Example |
|---------|-------------|---------|
| `ls -l` | View permissions | ```bash ls -l``` |
| `chmod` | Change permissions | ```bash chmod 644 file.txt``` |
| `chown` | Change owner | ```bash chown omkar file.txt``` |
| `chgrp` | Change group | ```bash chgrp devops file.txt``` |

---

## ⭐ 6️⃣ Quick Navigation Shortcuts

- `cd ~` → Go to home directory  
- `cd ..` → Go up one directory  
- `cd -` → Switch to previous directory  
- `tab` → Auto-complete file/directory names  
- `ctrl + r` → Reverse search in command history
