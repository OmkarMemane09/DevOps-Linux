# Linux Architecture & File System

## ⭐ Linux Architecture (Detailed)

Linux architecture is divided into **5 main layers**:

### 1️ Hardware Layer
- Physical components like CPU, RAM, storage, network devices, and peripherals.  
- Linux interacts with hardware **only via the kernel**.

### 2️ Kernel Layer
- Core component of Linux  
- **Responsibilities**:
  - Process management (scheduling, priorities)  
  - Memory management (RAM, swap)  
  - Device drivers (keyboard, disk, network)  
  - File system management  
  - Networking (TCP/IP stack)  
- Types of kernels:
  - Monolithic Kernel (Linux default)  
  - Microkernel (minimal features, more modular)

### 3️ System Libraries
- Libraries provide reusable **code for programs**.  
- Example: `glibc` (GNU C library) for standard file I/O, networking, and threading.  
- Programs call **library functions** instead of writing low-level code.

### 4️ Shell (Command Interpreter)
- Interface between **user & kernel**  
- Converts typed commands to system calls  
- Popular shells: `bash`, `zsh`, `fish`, `ksh`  
- **Example:**  
  ```bash
  echo "Hello, Linux"
   ```
### 5️ User Space / Applications

Programs run in user space (cannot directly access hardware)

Examples: Editors (vim, nano), Browsers, Utilities (curl, wget), DevOps tools (docker, kubectl)

 ## ⭐ Linux File System Hierarchy (FHS)
Linux organizes files in a tree structure starting from / (root).

Key Directories:
Directory	Description
```
/	Root of filesystem
/bin	Essential binaries (commands like ls, cp)
/sbin	System binaries (ifconfig, fdisk)
/etc	Configuration files
/home	User home directories
/root	Root user home
/var	Variable data (logs, databases, spool)
/tmp	Temporary files
/usr	User programs & libraries
/lib	Essential shared libraries
/dev	Device files (/dev/sda, /dev/null)
/proc	Kernel & process information (virtual filesystem)
/sys	System devices & kernel info
```
## ⭐ File System Types

-Ext4 – Most common Linux filesystem

-XFS – High-performance, large files

-Btrfs – Copy-on-write, snapshots

-FAT/NTFS – For cross-platform compatibility

-Swap – Virtual memory area

## ⭐ Processes & System Interaction
Linux treats everything as a file, even devices.

Processes run in user space and interact with kernel via system calls.

Commands like ps, top, htop monitor processes.

```bash
ps aux | grep nginx
top
```
